Documentation

Commands Reference

Search or explore all commands available in Sora CLI.

🔍
--check-account Authentication

Verifies your GitHub Personal Access Token and prints the authenticated username and rate limits.

--token <TOKEN>
sora --check-account
--set-token <TOKEN> Authentication

Saves your GitHub token permanently to ~/.sora/config.json for instant access across all terminal sessions.

--scope user --scope system
sora --set-token ghp_yourTokenHere
sora repos Repositories

Lists repositories owned by or accessible to your account, with visibility indicators, stars, and languages.

--visibility public|private --sort updated|stars --limit 30
sora repos --visibility private
sora create <name> Repositories

Creates a new GitHub repository under your account with custom privacy and description flags.

--private --desc "Description"
sora create my-api --private --desc "Backend service"
sora stats <repo> Analytics

Shows comprehensive repository statistics: stars, watchers, forks, open issues, default branch, size, and URLs.

alias: info owner/repo or repo
sora stats Muzic-x
sora push <repo> [path] File Operations

Uploads a local file or an entire directory recursively to GitHub with an optional target path and commit message.

--target <remote_dir> -m "Commit msg"
sora push my-repo ./dist --target build/ -m "Deploy v2"
sora pull <repo> File Operations

Downloads a repository archive directly via API and extracts it cleanly to a destination folder.

--dest ./output --branch main aliases: download, clone
sora pull my-repo --dest ./my-project
sora ls <repo> File Operations

Browses directory trees and file listings in any repository without having to clone it first.

--path src/ --files-only --folders-only --limit 50
sora ls my-repo --path src/
sora cat <repo> <file> File Operations

Prints the contents of a remote file directly to stdout in your terminal. Great for configs and READMEs.

--raw alias: read
sora cat my-repo package.json
sora branches <repo> Git Features

Lists all available branches in a repository along with their latest commit SHA hashes.

repo or owner/repo
sora branches my-repo
sora rename <old> <new> Repository Management

Renames an existing repository safely and updates the remote tracking URL.

alias: mv
sora rename old-project new-project
sora update <repo> Repository Management

Updates repository metadata including description, homepage URL, or toggles visibility between public and private.

--desc "New summary" --public --private --homepage <URL>
sora update my-repo --desc "Live version" --homepage https://app.dev
sora rm <repo> <path> File Operations

Deletes a remote file or folder with interactive confirmation prompts to prevent accidental deletions.

-m "Commit msg" --force aliases: remove, del
sora rm my-repo temp.log -m "Remove temp file"
sora delete <repo> Danger Zone

Permanently deletes a GitHub repository. Requires typing the repository name to confirm unless --force is passed.

--force
sora delete throwaway-repo

Troubleshooting

Frequently Asked Questions

Got questions? Find immediate answers to common issues below.

What GitHub token permissions do I need? +
You need a Personal Access Token (Classic) with the repo scope selected. This allows Sora to list private repositories, upload files, read repository statistics, and perform branch operations.
Why does it say "Invalid GitHub token"? +
This occurs when the token has expired, was revoked on GitHub, or was typed with a missing character. Re-run sora --set-token YOUR_TOKEN with a freshly generated token from GitHub Token Settings.
How do I run Sora without typing 'python' on Windows? +
The repository includes a sora.cmd file. Simply make sure the folder containing sora.cmd is added to your Windows User PATH, or copy sora.cmd into your Python Scripts directory.
Where is my token stored on my machine? +
It is saved in your home directory at ~/.sora/config.json (or C:\Users\<username>\.sora\config.json on Windows). The file is stored locally on your device and is never uploaded anywhere.
How to resolve NameResolutionError / DNS failure? +
This means your device temporarily lost internet connectivity or failed to resolve api.github.com. Run ipconfig /flushdns on Windows or verify your Wi-Fi/VPN connection.
