Installation

Select your platform for tailored installation steps.

# Clone and install requests
git clone https://github.com/MrTG-CodeBot/sora-github-cli.git
cd sora-github-cli
pip install requests

# Run directly with included sora.cmd
sora --set-token YOUR_TOKEN
sora --check-account
# Install environment in Termux
pkg update && pkg install python git -y
pip install requests

# Install globally to Termux bin
curl -o $PREFIX/bin/sora https://raw.githubusercontent.com/MrTG-CodeBot/sora-github-cli/main/sora
chmod +x $PREFIX/bin/sora
sora --check-account
# Install to system bin
sudo curl -o /usr/local/bin/sora https://raw.githubusercontent.com/MrTG-CodeBot/sora-github-cli/main/sora
sudo chmod +x /usr/local/bin/sora
pip install requests
sora --check-account
# Install to path
sudo curl -o /usr/local/bin/sora https://raw.githubusercontent.com/MrTG-CodeBot/sora-github-cli/main/sora
sudo chmod +x /usr/local/bin/sora
pip3 install requests
sora --check-account

Command reference

All available subcommands and options.

sora repos
List repositories with star counts and visibility
sora repos --limit 10
sora create
Create a new private or public repository
sora create app --private
sora stats
Display repository statistics and clone URLs
sora stats Muzic-x
sora push
Upload files or folders recursively to GitHub
sora push repo ./dist
sora pull
Download and extract repository archive via API
sora pull repo --dest ./dl
sora ls
Browse remote directory contents without cloning
sora ls repo --path src/
sora cat
Print remote file contents directly to stdout
sora cat repo file.json
sora branches
List repository branches and commit SHA hashes
sora branches my-repo
sora rename
Rename an existing GitHub repository
sora rename old-name new
sora update
Update repository description and visibility
sora update repo --desc "Text"
sora rm
Delete a remote file or folder with safety prompts
sora rm repo file.txt
sora delete
Permanently delete a repository with confirmation
sora delete test-repo

Frequently asked questions

Answers to common setup and technical questions.

What token permissions does Sora require? +
Sora requires a GitHub Personal Access Token (classic) with the repo scope selected. This allows listing private repositories, uploading code, and managing branches.
How does Sora store my token safely? +
Tokens are saved in your local user directory at ~/.sora/config.json with owner only read and write permissions (chmod 600). Your token stays on your device and is never transmitted to third party servers.
Why did an upload fail with a malformed request error? +
The GitHub REST Contents API enforces a 64 KB JSON payload limit. Files larger than 48 KB on disk exceed this threshold once encoded to base64. For files over 48 KB, minify file size or use Git for large binaries.
Can I run Sora without typing python on Windows? +
Yes. The repository includes sora.cmd. When placed in your Python Scripts directory or added to your User PATH, you can run sora directly from Command Prompt or PowerShell.
Does Sora work without root on Termux? +
Yes. Sora runs natively in Termux using standard Python 3. Copying the script to $PREFIX/bin/sora makes it globally accessible without root.
How do I update an existing repository token? +
Simply run sora --set-token with your new token. Sora updates ~/.sora/config.json immediately without requiring you to restart your terminal session.
