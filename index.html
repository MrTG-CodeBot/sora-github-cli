Installation

Sora is packaged as a standalone Python utility. It requires Python 3.6+ and the requests HTTP library.

On Windows, Sora includes sora.cmd so you can run sora from Command Prompt and PowerShell without typing python.

PowerShell / Command Prompt 
# 1. Clone repository
git clone https://github.com/MrTG-CodeBot/sora-github-cli.git
cd sora-github-cli

# 2. Install dependency
pip install requests

# 3. Add to user PATH or copy sora.cmd into Python Scripts directory
sora --version

Sora runs natively inside Termux on Android devices without root:

Termux 
pkg update && pkg install python git -y
pip install requests
curl -o $PREFIX/bin/sora https://raw.githubusercontent.com/MrTG-CodeBot/sora-github-cli/main/sora
chmod +x $PREFIX/bin/sora
sora --version

Install Sora into /usr/local/bin to run system-wide:

Bash / Zsh 
sudo curl -o /usr/local/bin/sora https://raw.githubusercontent.com/MrTG-CodeBot/sora-github-cli/main/sora
sudo chmod +x /usr/local/bin/sora
pip install requests

Download Sora to your path using Terminal:

macOS Terminal 
sudo curl -o /usr/local/bin/sora https://raw.githubusercontent.com/MrTG-CodeBot/sora-github-cli/main/sora
sudo chmod +x /usr/local/bin/sora
pip3 install requests

Authentication

Sora authenticates with the GitHub REST API using a Personal Access Token (classic).

Required Token Scope
Generate a token with the repo scope selected at github.com/settings/tokens. This enables access to private repositories and code uploads.
Terminal 
# Save token permanently to ~/.sora/config.json
sora --set-token ghp_yourTokenHere
✓ Token saved to configuration: ~/.sora/config.json

# Verify
sora --check-account
✓ Connected as: MrTG-CodeBot

Credential Resolution: Sora checks credentials in order: --token <ARG> > ~/.sora/config.json > $GITHUB_TOKEN.

Command Manual

GET sora repos
sora repos [--visibility {all,public,private}] [--sort {created,updated,pushed}] [--limit INT]

Lists repositories owned by or accessible to your account.

FlagTypeDescription
--visibilitystringFilter: all, public, private (default: all)
--sortstringSort: created, updated, pushed (default: updated)
--limitintMax repositories to display (default: 30)
 
sora repos --visibility private --limit 10
POST sora create
sora create <name> [--private] [--desc TEXT]

Creates a new GitHub repository under your user account.

FlagTypeDescription
<name>stringRepository name
--privatebooleanSet repository to private
--descstringRepository description
 
sora create my-api --private --desc "Backend REST service"
GET sora stats
sora stats <repo> (alias: info)

Shows repository statistics: stars, watchers, forks, open issues, size, and URLs.

sora stats Muzic-x
GET sora view
sora view <repo>

Shows repository metadata and clone URLs.

sora view sora-github-cli
PUT sora push
sora push <repo> [path] [--target REMOTE_DIR] [-m MESSAGE]

Uploads a local file or an entire directory tree recursively to a remote repository.

FlagTypeDescription
<repo>stringRepository name
[path]stringLocal path (default: current directory .)
--targetstringTarget remote directory path
-mstringCommit message
 
sora push my-repo ./dist --target build/ -m "Deploy build"
GET sora pull
sora pull <repo> [--dest PATH] [--branch NAME] (aliases: download, clone)

Downloads a repository archive directly via API and extracts it cleanly.

FlagTypeDescription
--deststringDestination path (default: ./<repo>)
--branchstringBranch to download (default: default branch)
 
sora pull my-repo --dest ./backup
GET sora ls
sora ls <repo> [--path PATH] [--files-only] [--folders-only]

Lists remote repository directory contents without cloning.

sora ls my-repo --path src/components
GET sora cat
sora cat <repo> <file> [--raw] (alias: read)

Reads and prints remote file contents directly to terminal stdout.

sora cat my-repo config.json
GET sora branches
sora branches <repo>

Lists all branches in a repository with their latest commit SHA.

sora branches my-repo
PUT sora rename
sora rename <old_name> <new_name> (alias: mv)

Renames a GitHub repository.

sora rename legacy-project modern-project
PUT sora update
sora update <name> [--desc TEXT] [--public | --private] [--homepage URL]

Updates repository settings such as description, homepage link, or changes visibility.

sora update my-repo --desc "Production service"
DEL sora rm
sora rm <repo> <path> [-m MESSAGE] [--force] (aliases: remove, del)

Deletes a file or directory from a remote repository.

sora rm my-repo temp.log -m "Remove logs"
DEL sora delete
sora delete <name> [--force]

Permanently deletes a GitHub repository with safety confirmation.

sora delete throwaway-repo

Common Workflows

1. Direct Project Backup

Download a remote project zip directly and extract it to a local folder:

sora pull Muzic-x --dest ./Muzic-x-backup

2. Deploy Directory Trees

Upload a generated build folder straight to a remote GitHub repository:

sora push website-repo ./build --target dist/ -m "Deploy build"

Troubleshooting

Invalid GitHub Token (HTTP 401)

Verify your token is active and has the repo scope, then save it:

sora --set-token ghp_yourNewTokenHere

NameResolutionError / DNS failure

Occurs during temporary network disconnects. On Windows, flush DNS cache:

ipconfig /flushdns

File Upload Payload Limit (64 KB)

GitHub Contents API enforces a 64 KB JSON request payload limit per file. For files larger than 45 KB uncompressed, minify assets or push via Git.
