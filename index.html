Installation

Sora is packaged as a standalone Python script. It requires Python 3.6+ and the requests package. Choose your platform below:

On Windows, Sora includes sora.cmd allowing execution directly from Command Prompt or PowerShell without prepending python.

PowerShell / Command Prompt 
# 1. Clone repository
git clone https://github.com/MrTG-CodeBot/sora-github-cli.git
cd sora-github-cli

# 2. Install dependency
pip install requests

# 3. Add to user PATH or copy sora.cmd into your Python Scripts directory
sora --version

Sora runs natively inside Termux on Android devices without root requirements:

Termux (Android) 
# Install environment
pkg update && pkg install python git -y
pip install requests

# Install sora globally into Termux bin
curl -o $PREFIX/bin/sora https://raw.githubusercontent.com/MrTG-CodeBot/sora-github-cli/main/sora
chmod +x $PREFIX/bin/sora

# Verify
sora --version

Install Sora to /usr/local/bin to run it system-wide:

Bash / Zsh 
# Download and make executable
sudo curl -o /usr/local/bin/sora https://raw.githubusercontent.com/MrTG-CodeBot/sora-github-cli/main/sora
sudo chmod +x /usr/local/bin/sora

# Install dependencies
pip install requests

On macOS, copy the binary to your local executable path:

Terminal (zsh) 
sudo curl -o /usr/local/bin/sora https://raw.githubusercontent.com/MrTG-CodeBot/sora-github-cli/main/sora
sudo chmod +x /usr/local/bin/sora
pip3 install requests

Authentication

Sora authenticates with the GitHub REST API using a Personal Access Token (classic).

Required Token Scope
Generate a token with the repo scope selected at github.com/settings/tokens. This grants access to private/public repositories and code uploads.
Terminal 
# 1. Save token permanently to ~/.sora/config.json
sora --set-token ghp_yourTokenValueHere
✓ Token saved to configuration: ~/.sora/config.json
ℹ Ready to use immediately across all terminals!

# 2. Check connected account
sora --check-account
✓ Connected as: MrTG-CodeBot

Token Resolution Priority: Sora checks credentials in this order: --token <CLI_ARG> > ~/.sora/config.json > $GITHUB_TOKEN environment variable.

Command Manual

Reference documentation and flags for every Sora subcommand.

sora repos sora repos [--visibility {all,public,private}] [--sort {created,updated,pushed,full_name}] [--limit INT]

Lists repositories associated with your account, displaying visibility badges, stars, language, and repository size.

Flag Type Description
--visibility string Filter by all, public, or private (default: all)
--sort string Sort order: created, updated, pushed (default: updated)
--limit int Maximum number of repositories to display (default: 30)
Example 
sora repos --visibility private --limit 10
sora create sora create <name> [--private] [--desc TEXT]

Creates a new GitHub repository under the authenticated user account.

Flag Type Description
<name> positional The name of the repository to create
--private boolean Make repository private (default: public)
--desc string Repository description string
Example 
sora create sora-api --private --desc "Backend REST service"
sora stats sora stats <repo> (alias: info)

Retrieves engagement analytics for a repository, including stars, forks, open issues, watchers, size, and URLs.

Example 
sora stats Muzic-x
sora view sora view <repo>

Shows concise repository metadata and remote git clone URLs.

Example 
sora view sora-github-cli
sora push sora push <repo> [path] [--target REMOTE_PATH] [-m MESSAGE]

Uploads a local file or an entire directory tree recursively to a remote repository.

Flag Type Description
<repo> positional Repository name (or owner/repo)
[path] positional Local file or directory path (default: current directory .)
--target string Destination folder inside the remote repository
-m, --message string Git commit message
Example 
sora push my-repo ./dist --target build/ -m "Deploy v2.1.0 assets"
sora pull sora pull <repo> [--dest PATH] [--branch NAME] (aliases: download, clone)

Downloads a repository archive directly through the GitHub API and unpacks it to a target directory without requiring a git client.

Flag Type Description
--dest string Destination directory (default: ./<repo>)
--branch string Specific branch to download (default: repository default)
Example 
sora pull my-app --dest ./backup-project --branch main
sora ls sora ls <repo> [--path PATH] [--files-only] [--folders-only] [--limit INT]

Lists files and directories inside a remote repository without cloning.

Example 
sora ls my-repo --path src/components
sora cat sora cat <repo> <file> [--raw] (alias: read)

Reads and prints the content of a remote file directly into stdout.

Example 
sora cat my-repo config.json
sora branches sora branches <repo>

Lists all branches in the specified repository with their latest commit SHA.

Example 
sora branches my-repo
sora rename sora rename <old_name> <new_name> (alias: mv)

Renames a GitHub repository.

Example 
sora rename legacy-bot modern-bot
sora update sora update <name> [--desc TEXT] [--public | --private] [--homepage URL]

Updates repository settings such as description, homepage link, or changes visibility.

Example 
sora update my-repo --desc "Production ready" --homepage https://myproject.org
